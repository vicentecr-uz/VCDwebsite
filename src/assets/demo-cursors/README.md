# Demo cursor assets

These are unmodified SVG exports from [Apple macOS 26 Cursors](https://www.figma.com/community/file/1517119747499682321/apple-macos-26-cursors) by Kévin GATTUSO, shared under the [Creative Commons Attribution 4.0 International license](https://creativecommons.org/licenses/by/4.0/).

The exports come from the pointing1:18, open1:20, and grabbing1:22 nodes. The demo applies presentation-only wrapper positioning and scale to preserve the guide's existing cursor size and hotspots.
